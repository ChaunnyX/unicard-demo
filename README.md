# Unicard — демо-витрина

Финтех-маркетплейс цифровых товаров с «выдачей за секунды». Полное демо без бэкенда:
все данные canned (`src/data/`), состояние (баланс/заказы/подписки) — в localStorage.

## Запуск

```bash
pnpm install
pnpm dev            # localhost:5173
pnpm tsc -b && pnpm vite build   # прод-сборка в dist/
npx wrangler deploy --temporary  # публичная ссылка *.workers.dev
```

## Что внутри

- **Витрина**: главная (живой фид выдач, моментальная покупка, товары дня с таймером),
  8 каталогов — у каждого свой вау-блок (eSIM — интерактивная карта мира, VPN — тёмный
  лендинг с маршрутом трафика и замером 185 Мбит/с, прокси — калькулятор, карты — 3D-tilt
  Mastercard, переводы — калькулятор с курсом и дугами на карте), полная страница товара
  с кросс-сейлом.
- **Signature-флоу покупки**: оплата с баланса → пайплайн «оплата → закупка → выдача» →
  код печатается посимвольно → штамп «выдано за N с».
- **Кабинет**: баланс с докруткой, пополнение (гейт «не хватает N ₽»), заказы с кодами,
  подписки с QR и продлением, страница подключения VPN, выпуск виртуальной карты, заявки на переводы.
- **Админка** (`/admin`): выручка/прибыль/график, доли категорий, остатки депозитов
  у поставщиков, наценки по категориям, заказы, пользователи с ручными операциями.

## Демо-вход

«Войти через Telegram» — мгновенно логинит демо-пользователя с балансом 1 250 ₽,
двумя заказами и активной VPN-подпиской.

## Стек

Vite + React 19 + TS strict + Tailwind 4. Шрифты: Tektur / Onest / JetBrains Mono
(self-hosted через fontsource). Иконки lucide. Карта — dotted-map (генерация
`node scripts/genmaps.mjs` → `public/img/maps/world.svg` + `src/data/mapPins.json`).
Обложки игр — Steam CDN, флаги — flagcdn (лежат в `public/img/`).

Цены и модель — из аудита поставщиков (`~/Downloads/unicard-suppliers.html`):
VPN 299/499 ₽, eSIM от 169 ₽, комиссия пополнения Steam 10%, карта $10 + $5/мес и т.д.
